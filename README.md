# 💼 Job Listings React App

A simple React application that displays job openings using reusable card components.  
Each job card shows company details, role, job type, experience level, pay rate, and location.

---

## 🚀 Features

- 📦 Static job data stored as an array of objects
- ♻️ Reusable `Card` component
- 🖼 Supports Base64 and URL-based company logos
- 🧩 Clean component-based architecture
- ⚡ Fast rendering using `map()`

---

## 🛠 Tech Stack

- **React (JSX)**
- **JavaScript (ES6+)**
- **CSS** (custom or framework-based)
- **Vite / CRA** (depending on setup)
